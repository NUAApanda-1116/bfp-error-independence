\begin{abstract}
Selecting a shared quantization scale from a block maximum couples the
rounding errors, but conditioning on the scale does not in general restore independence.
For independent, identically distributed inputs, we derive exact finite-block
error moments using one-dimensional truncated distributions. The conditional
pair covariance is always nonpositive and has a closed formula; variation of
the conditional mean supplies a competing positive contribution. The resulting
covariance matrix gives exact variance and mean-square error formulas for
deterministic weighted reductions. Retaining the exact conditional moments
while omitting the negative conditional covariance overestimates the variance
inflation factor by at most one, independently of the input law and block
length. Symmetric inputs and independently randomized stochastic rounding give
zero pair covariance, whereas asymmetric inputs can produce either variance
inflation or deflation. Bounded support with a nondegenerate limiting error
gives unit inflation asymptotically. Unbounded support with finite second moment
gives vanishing pair correlation, but does not guarantee vanishing inflation:
for exponential inputs we prove divergence along a dyadic subsequence.
A unified computational study checks the formulas against Monte Carlo
experiments and exact rational enumeration, and measures the effects of weight
balance and block partition on reduction errors. The analysis concerns a
uniform integer-mantissa block grid and isolates input quantization from
subsequent arithmetic rounding.
\end{abstract}

\section*{Data and code availability}
The accompanying reproduction package contains the experiment driver, saved
machine-readable results, figure and table generator, high-precision evaluator,
exact rational enumeration oracle, and a manifest with random seeds, package
versions, execution times, and file hashes. The figures and tables in this
manuscript are generated from that package. The earlier experiment records
are retained separately and are not used as the numerical evidence for the
revised results. The existing project repository is
\url{https://github.com/NUAApanda-1116/bfp-error-independence}; the accompanying
revision package specifies the files required to reproduce this version.
